# Model card: practitioner-post topic classifier

_Generated by `signals model-card` from `reports/topic-eval.json` (2026-10-25). Don't edit by hand._

## What it does

Assigns one of five topics to a short English summary of a practitioner's post about coding agents, so new posts can be filed on the AI Engineer Log's community page without reading each one first.

| Topic | Meaning |
| --- | --- |
| `agent-workflow` | How to drive coding agents day to day: planning, sessions, parallel agents, tool choice. |
| `token-cost` | Token use, context size, caching and what agent work costs. |
| `instructions-context` | Instruction files (AGENTS.md, CLAUDE.md), skills, rules and what context to give an agent. |
| `review-evals` | Reviewing agent output: code review, tests, hooks, guardrails and evals. |
| `career` | Jobs, hiring and skills for AI engineers. |

## Data

- 35 posts from Threads, summarised in my own words (originals: 17 KO, 18 EN).
- Topic counts: token-cost 7, agent-workflow 5, review-evals 9, instructions-context 7, career 7.
- Reference labels: 0 of 35 reviewed by me; the rest are the labels assigned when the posts were curated with an agent's help. Until more are reviewed, agreement with the reference is not the same as accuracy.

## Results

| Method | Accuracy | Macro F1 |
| --- | ---: | ---: |
| Majority class | 26% | – |
| TF-IDF + logistic regression (CV) | 69% | 0.64 |
| LLM zero-shot (claude-haiku-5-5) | 91% | 0.90 |

- Baseline: TF-IDF (1-2 grams) + logistic regression, 5-fold stratified CV, seed 0.
- LLM: Zero-shot labelling by claude-haiku-5-5 via claude -p, one call for all posts; $0.0024 for the whole set.
- Posts where the LLM and the reference disagree (3): t21, t27, t31. These are the first to review by hand.

## Limits

- The dataset is tiny, so one post moves accuracy by about three points. Treat differences under ten points as noise.
- Topics overlap: a post about short instruction files to save tokens fits two topics. One label per post loses that.
- Summaries are mine, not the original wording, so the classifier learns my phrasing as much as the authors'.
